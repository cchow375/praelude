## Camera contract

Camera is off by default. Explicit enable requests Camera permission. One app-wide score owner and a serialized AVCapture video-only worker runs Vision at at most10Hz with late-frame discard. No microphone input, image/video file writer, person identification or network/frame upload path exists. No frames or calibration are synced or backed into the practice library; action preferences are device-local. Background/score exit stops capture and invalidates queued callbacks; camera interruptions require explicit restart and calibration.

Neutral calibration uses a recent steady second of a single face. Pose, lip-width relative to eyes, confidence, face size and facial-region luminance gate detection. Smile geometry is an estimate, not emotion recognition or a promise of accuracy. Gestures complete only on return to neutral, then cooldown and neutral rearm. Low light, uncertain mapping, multiple faces, delayed/gapped frames and mixed motion cannot dispatch. Rotation clears calibration. Settings panel remains test-only. Score/editor/focus/set guards are checked again at action dispatch. Camera verdicts require an explicit separate opt-in and an active running set; no automatic playing grade or cold-grade inference occurs. Page actions remain available in score focus.

API basis: [Apple Vision face observations](https://developer.apple.com/documentation/vision/vnfaceobservation), [face landmarks request](https://developer.apple.com/documentation/vision/vndetectfacelandmarksrequest), [speech audio-buffer request](https://developer.apple.com/documentation/speech/sfspeechaudiobufferrecognitionrequest). SDK headers verify radians/pitch availability and supported camera rotation checks. API compatibility does not prove physical mapping or speech reliability.
