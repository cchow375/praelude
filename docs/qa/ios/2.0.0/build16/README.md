## Final threading contract

Apple current [AVCam](https://developer.apple.com/documentation/avfoundation/avcam-building-a-camera-app) puts view-backed preview session assignment and preview rotation on MainActor. Build16 matches it using an asynchronous logical FIFO: background capture operations, acknowledged main preview operations, then the next capture job. Neither executor synchronously waits for the other. The native main-ack regression passes.
