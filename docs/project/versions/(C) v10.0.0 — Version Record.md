## What this version is

v10 is the point where CodaKiller becomes **Praelude** and the whole visible product adopts one
coherent, dark, modern interface. It is a product-identity and frontend release, not a change to
the user-as-sensor model or practice-data schema.

The rename covers the customer-facing product, macOS app bundle name, executable, package and
window titles, onboarding/tutorial/settings language, spoken online phrase, app icon, new-install
wake word and future packaging output. Historical artifacts stay historically named.

The bundle identifier `com.christian.codakiller`, application-support directory, database
filename, Keychain service, durable browser keys and old generated session-log filename remain
unchanged. Those are deliberately hidden compatibility identifiers: renaming them would create a
new macOS permission identity or strand the existing database and settings.

## What shipped

- Dark mode is the default and fixed presentation for the current release.
- SF Pro/system sans replaces serif/display typography everywhere.
- A restrained near-black/neutral palette uses one quiet blue-white accent.
- Navigation is narrower and calmer; selection and hierarchy no longer depend on many colors.
- Primary controls have larger targets while secondary explanation and chrome are reduced.
- Today, Pieces, Score, History, Calendar, Universe and Settings use the same tokens and surfaces.
- Score remains one-page-at-a-time by default, with page arrows and optional two-page view.
- Selecting a passage opens its Practice set; Variants and secondary Settings open as centered
  dialogs over a blurred background. Left/right-hand and other variants remain available.
- Settings disclosures start collapsed instead of presenting a wall of text.
- A new monochrome Praelude “P” icon ships across macOS and generated platform icon sizes.
- Future Mac and Windows packaging scripts produce Praelude-named artifacts.
