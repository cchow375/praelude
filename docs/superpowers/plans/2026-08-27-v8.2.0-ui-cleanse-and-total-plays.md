## Goal

Remove the time and visual friction Christian found in the real Score/practice surfaces. Reading
must feel like reading a document, the practice composer must reveal the controls he chose without
making him hunt, and a volume drill must be expressible without falsely becoming mastery.

## Product contract

### Continuous Score

- The Score is one continuous scroll, not a single pinned page with blank canvas below it.
- Every in-scope PDF page owns a persistent size-correct slot; only intersecting pages plus bounded
  overscan mount expensive PDF canvases, capped at five.
- The dominant visible page updates page navigation and the active Pencil page.
- Page field, previous/next buttons and keyboard page commands scroll directly to the target slot.
- **2-page view** is a continuous two-column overview, not a separate paged mode.
- The PDF and Tricky Sections rail scroll independently inside the workspace. Expanding a section
  reveals its practice composer in the rail, including at 720×520.

### Decluttered control hierarchy

- Edition/movement, page navigation and zoom remain immediate.
- Fit width, Fit page, 2-page view, drawing, Pencil and mapping live under **Score tools**.
- The bottom bar keeps **Paused Sets** and **Rep Counter** direct. Clock, Dynamics and Rotation are
  grouped in a keyboard-accessible **Tools** menu with urgency preserved.
- Variant presets use one horizontally scrolling chip line. Each configured variant is one compact
  32px row: order, name, consecutive-clean count and reorder/delete controls stay inline.
- The Set Composer's body is allowed to flow inside the independently scrolling rail; it does not
  create a nested fixed-height page.
- **v8.2.1 correction:** the core measure and BPM fields are paired in two columns; Focus shares a
  line with Metronome; target mode shares a line with its count; Start stays in the pinned form
  header; and custom variant text entry appears only after **+ Custom**. This keeps the action
  reachable without adding a second scroll container.

### Total plays contract

- **Set target** has a roving-tabindex, arrow/Home/End-correct **Clean streak / Total plays** choice.
- Clean streak preserves the existing 3/5/7/10/Custom target, ladder, demotion, variants and
  clean-governed mastery semantics.
- Total plays offers 5/10/15/25/Custom. It is a fixed-tempo volume set: no target BPM, ladder,
  demotion, variant chain or review boundary is active or shown.
- Every effective non-void Clean, Sloppy and Again adds one. Undo removes one from projection.
- At the target, the normal bounded close countdown may run. This is **target completion, not
  mastery**: History, Score summaries, day aggregates, Universe and completion effects must never
  turn it into verified mastery or a mastery badge/landing.
- Switching target modes preserves the variant draft in the current composer session so exploring
  Total plays does not destroy work.

### v8.2.1 safe day-close and camera contract

- Plain **End session** closes only the session. It never opens the day-photo ritual or requests a
  camera.
- Only a separately confirmed **End my day** offers the optional photo card. Merely rendering the
  card requests no device; **Use camera** is the explicit request action.
- A synchronous missing/throwing media API and an asynchronous permission rejection both fall
  back to drop/choose-file mode. Skip/Escape remain immediate and any acquired stream is stopped.
- `src-tauri/Info.plist` includes a truthful `NSCameraUsageDescription`. The release script rejects
  any built bundle missing camera, microphone or speech-recognition usage descriptions.
- This is installed-resolved B95. v8.2.0 remains the historical binary that crashed after session
  48; its data was preserved and the orphan `hear` PID was cleaned up.
