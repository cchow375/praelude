## Goal

Produce one blank, share-clean, current-user x64 NSIS Setup EXE that a pianist can install on
Windows 10 or 11 and use for Pieces/PDF organization and keyboard/mouse practice. This is the same
generic product, never a personal friend fork.

## Binding scope

### Supported in the first Windows port

- blank app-owned first launch and schema-21 local database;
- Pieces Library, nested logical folders, Unfiled and Active/Completed/Archived actions;
- direct local-PDF picker/drop intake and optional IMSLP browser handoff;
- Score rendering and platform-correct score URLs;
- keyboard/mouse Clean, Sloppy, Again, Undo and set/session controls;
- native metronome/chimes, History, Calendar and local persistence;
- Windows-safe file/folder/path/cache behavior; and
- current-user x64 NSIS packaging with WebView2 bootstrap behavior.

### Explicitly unavailable

- `hear`/native STT and Mic controls;
- hands-free voice commands;
- Listen Back and its microphone ownership/capture lease;
- macOS `say` and macOS system-volume boost;
- Windows on Arm, automatic updates or warning-free signed distribution.

No Windows code-signing certificate exists. The artifact is expected to be unsigned; SmartScreen
is an acceptance step, not a condition to disguise.

## Work phases

### 1. Portability boundary

- Replace hard-coded macOS score URL, browser/file opener, picker, home/download and reveal paths
  with target-aware implementations.
- Keep macOS STT behavior intact; compile a Windows unsupported supervisor that reports the
  platform boundary without spawning `hear`.
- Hide/disable Mic, voice, volume and Listen Back surfaces on Windows with truthful copy.
- Sanitize Windows-invalid/reserved piece folder names and normalize trash/path projections.
- Make page-cache replacement and durability behavior safe on Windows.

### 2. Windows package boundary

- Use `src-tauri/tauri.windows.conf.json` to target NSIS/current-user x64.
- Exclude the Mach-O `vendor/bin/hear` resource.
- Run the Windows workflow on a real Windows runner: frontend tests/build, Rust format, strict
  Clippy, native tests and Tauri NSIS build.
- Stage exactly one versioned Setup EXE, a basename-only SHA-256 sidecar and a build-status record.
- Run the Windows share-clean inspection and record Authenticode honestly.

### 3. Artifact and recipient acceptance

- Record exact filename, size, SHA-256, Authenticode status, runner and run URL/ID.
- Install on clean Windows 10 and Windows 11 x64.
- Verify SmartScreen, current-user install, blank first launch, first PDF, Score, folders/actions,
  a keyboard/mouse practice set, restart persistence and uninstall/reinstall.
- Confirm Mic/voice/Listen Back never present themselves as working.

### 4. Release truth

- Update QA/version/living docs with measured results only.
- Commit/tag/push only after the Windows artifact boundary is factual.
- Do not call the installer recipient-accepted until clean Windows 10 and 11 evidence exists.
- Do not change the packaged Mac v9.0.0 facts or claim that v9.1 is installed on Christian's Mac.
